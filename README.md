# 🎮 Cat Pin Pull Game (Unity 2D)

A 2D puzzle game developed with **Unity**.  
The player pulls pins to guide fish to the cat while avoiding lava.

This project is built as a **portfolio project** to demonstrate gameplay logic, physics handling, and UI flow in Unity.

---

## 🧠 Gameplay
- Pull pins in the correct order to release fish
- Fish uses **2D physics** (Rigidbody2D + Collider2D)
- Wrong pin pull may cause lava to flow
- **Win**: Fish reaches the cat  
- **Lose**: Fish falls into lava or running out of time.

---

## 🛠️ Main Features
- Custom **pin drag system** (drag along pin direction, not animation-based)
- Physics-based fish movement
- Fake liquid lava effect (2D)
- Scene transition with fade animation
- Level system with auto-increment
- UI system: Menu, Win, Lose panels
- Clean GameManager & UI logic separation

---

## 🧩 Technologies Used
- **Unity 2D**
- **C#**
- Rigidbody2D, Collider2D
- Animator & Coroutine
- TextMeshPro
- Prefab system

---

## 🕹️ Controls
- **Mouse click + drag** to pull pins
- UI buttons: Play, Restart, Next Level, Menu

---

## ▶️ How to Run
1. Clone this repository
2. Open the project using **Unity Hub**
3. Open the `Menu` scene
4. Press **Play**
